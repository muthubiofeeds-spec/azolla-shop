GITHUB PAGES
1. Upload the contents of this folder to the repository root.
2. Repository Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
3. Add custom domain: azolla.shop
4. In GoDaddy DNS, point the domain to the GitHub Pages records shown by GitHub.
5. Enable HTTPS after DNS is active.
